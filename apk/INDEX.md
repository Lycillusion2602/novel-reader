## 重新出包

`npx cap sync android` → `cd android && gradlew assembleDebug`，
产物在 `android\app\build\outputs\apk\debug\app-debug.apk`。

**出完一定要比对包内页面与源码是否逐字节一致**，别拿一个装着旧页面的包去测：

【本机】
```
for f in js/app.js js/shelf.js js/parser.js js/db.js index.html css/style.css; do unzip -p 包 "assets/public/$f" | cmp - "www/$f" && echo "$f ✓"; done
```
