> **覆盖安装是安全的**：这个包和 9/21 那几个用同一把调试密钥
> （证书 SHA-256 `09125fbe5ff8d9c0edfd2255b2cadf29709552b815dcdd5d001bdf1ac9489819`），
> 所以 `adb install -r` 能直接盖上去，**手机里已导入的书和阅读进度都不会丢**。
> 哪天 `~/.android/debug.keystore` 换了就会签名不一致，那时系统会拒绝覆盖安装 ——
> 别急着卸载，先导书或确认能接受清空。
>
> 装：`adb install -r apk\20261002-2048_修9处问题.apk`（小米还要开「USB 安装」）。
> 这些包内容互不相同（SHA-256 已逐一比对，无重复），是对应修复点的历史留档，不需要就整目录删除即可。
> 重新出包：`npx cap sync android` → `cd android && gradlew assembleDebug`，
> 产物在 `android\app\build\outputs\apk\debug\app-debug.apk`；
> **出完一定要比对包内 `assets/public/js/app.js` 与 `www/js/app.js` 是否逐字节一致**，
> 别拿一个装着旧页面的包去测（`unzip -p 包 assets/public/js/app.js | cmp - www/js/app.js -`）。
